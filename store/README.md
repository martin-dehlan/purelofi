# Store assets

`brand/` holds the logo files the consoles ask for, written by
`python3 tool/brand_exports.py <scene folder>` (#93). Upload them by hand:

| File | Where |
|---|---|
| `app-store-icon-1024.png` | App Store Connect, app icon |
| `play-icon-512.png` | Play Console, app icon |
| `play-feature-graphic-1024x500.png` | Play Console, feature graphic |
| `oauth-logo-120.png` | Google Cloud, OAuth consent screen logo |
| `avatar-512.png` | RevenueCat app icons, any square avatar |
| `mark-96.png`, `mark-192.png` | The mark alone, on transparency |

Screenshots and listing copy live in `listing/` (#94).
